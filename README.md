# Service Website

Website sederhana untuk menampilkan informasi layanan, portofolio, dan kontak.  
Dibuat sebagai contoh proyek web statis menggunakan **HTML + CSS**, serta integrasi kontak melalui **WhatsApp**.

## 📂 Struktur Halaman
- `index.html` → Halaman utama (Home)
- `about.html` → Informasi tentang layanan/penyedia
- `services.html` → Daftar layanan yang tersedia
- `portfolio.html` → Portofolio proyek
- `contact.html` → Halaman kontak dengan form kirim pesan via WhatsApp
- `assets/css/style.css` → File CSS untuk styling

## ✨ Fitur Utama
- Navigasi sederhana antar halaman
- Tampilan responsif dengan CSS dasar
- Form kontak yang langsung terhubung ke WhatsApp
- Portofolio untuk menampilkan proyek/layanan
